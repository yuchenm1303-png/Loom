下面是 src/components/account-auth.css 的真实样式，未做任何改动，只把 --token 变量按深色 / 浅色两套主题分别注入，并让原本全屏固定的遮罩层只覆盖各自的预览框。 右侧浅色列由左侧克隆生成，保证两边结构完全一致。

这是一次性的评审页，改完样式后重新内联 CSS 即可刷新（在 desktop-react/ 下执行）。 注意命令里的 html[data-loom-theme= 前缀替换：组件 CSS 用 html[data-loom-theme="light"] 选择器，而本页把两套主题并排放在同一个 <html> 下，所以把前缀去掉、改挂在列容器上。 

node -e "const fs=require('node:fs');const t='design/account-dialog-preview.html';const c=fs.readFileSync('src/components/account-auth.css','utf8').trimEnd().replaceAll('html[data-loom-theme=\"light\"]','[data-loom-theme=\"light\"]');let h=fs.readFileSync(t,'utf8');h=h.replace(/\/\* ===BEGIN ACCOUNT CSS=== \*\/[\s\S]*?\/\* ===END ACCOUNT CSS=== \*\//,()=>'/* ===BEGIN ACCOUNT CSS=== */\n'+c+'\n/* ===END ACCOUNT CSS=== */');fs.writeFileSync(t,h)"

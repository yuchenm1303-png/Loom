# 动画语言：整个应用一套时间、一套曲线、一套规矩（2026-10-18）

起因：用户说“我想统一一下 loom 整个应用的动画语言，比如各种展开面板，界面切换等等”，看完现状后又说“你直接做好吧，动画本身也可以随意优化，也可以随便改所有代码按你的思路来”。
上一轮的 `docs/panel-language-2026-10-16.md` 只统一了**面板**；这一轮是**所有表面**：展开、折叠、浮层、菜单、提示、页面和会话切换、文字出现的方式。

> 2026-10-21 的《动效的手感》（`docs/motion-feel-2026-10-21.md`）在这把尺子上接着改：退出曲线 `in` 换成了第一帧就动的 `exit`，停靠面板和侧栏不再截图、离开走 fast-out，出现过程改用 `@starting-style`，按下归 `src/motion/press.css`，工具坞和循环的节拍也上了尺子。下文的 a61 快照、`in` 曲线和工具坞豁免是 10-18 当时的样子。

- 切换会话：内容抬起 180ms（3px）+ 选中滑块 260ms + 标题 320ms（位移 4px、模糊 2px）。
- 新对话：羽毛笔 640 + 首页文字上浮 560ms（10px，错开 70/140）+ 骨架脉冲 1300 + 标题 320。
- 设置翻页：一次点击 7 条以上（滑块滑动并拉伸、光晕 560、图标回弹 460、导轨 230、导航图标 210、正文透明度阶梯 230）。
- 展开 / 折叠：180–380ms，九条曲线；过程展开 320ms `.22,.74,.18,1`，收起 300ms `.4,0,.2,1`。
- 弹出：输入框浮层 100ms（透明度 .72 起步，退出 205）、会话右键菜单 220ms、模型面板内切页 210ms 位移 8px，CSS 里还有 160 / 175 / 190 / 220 的变体，位移 3–8px、缩放 .98–.995。

产品自己定的规则是“带字、原地出现的东西只淡入，位移留给无字的标记”。首页上浮、toast、部分浮层、标题模糊都违反它。

## 二、现在的语言

`src/motion-tokens.css` 是**唯一**选时间和曲线的地方（第一个加载）；`src/motion/tokens.ts` 把同样的数字给需要知道“要多久”的代码（定时器、Web Animations、`useMotionPresence` 的保留时长），`tests/test_motion_scale_contract.py` 让两边必须相等。

### 时间：六档，退出比进入短

| 档 | 进入 | 退出 | 谁 |
| --- | --- | --- | --- |
| press | 90 | — | 按下的回答（`:active`、图标按下） |
| fast | 150 | 120 | 回应一只手的一切：悬停、聚焦、提示、浮层、菜单、toast |
| base | 240 | 200 | 原地出现：对话框、页面、遮罩、一块内容、几行的折叠 |
| flow | 320 | 260 | 改变大小或位置：一块内容 / 一个列表的折叠、切换、无字标记的移动 |
| panel | 390 | — | 停靠面板和随之而来的布局移动（a61，测试钉死） |
| slow | 520 | — | “画出来”而不是“显示出来”：进度条填充、弹簧落定、光 |

错开（stagger）是 40ms。

### 曲线

`out` 到来（就是 a61 的深度曲线 `.16,.78,.18,1`）· `in` 离开 · `move` 改变大小或位置（`.22,.7,.18,1`，布局 FLIP 和折叠）· `inout` 收起时要软起软停 · `glide` 无字标记的长距离移动。弹簧三条：`soft`（3% 过冲）、`lively`（12%，让一个图形“活”）、`pop`（10%，珠子和状态点的诞生）。只有无字的小标记可以过冲。

### 三条规矩

1. **带字的不动。** 带字的东西只淡入淡出（淡入从 .72 起步，所以第一帧就读得清），空间由布局造出来（折叠 = `grid-template-rows` 0fr ↔ 1fr）。能动的是无字的标记（选中滑块、图标、珠子、进度、光点），和边缘来的停靠面板（a61）。
2. **一次交互一个主角。** 一次点击里只有一件东西在走，其余是透明度或不动。
3. **离开比到来短，而且每个出现的东西都能离开。** 任何东西都不会在一帧里被卸掉（保留时长 = 退出时长 + 一个余量，`RETAIN`）。

### 五种方言（每个表面只属于一种）

| 方言 | 谁 | 怎么动 |
| --- | --- | --- |
| 边缘（dock） | 侧栏、右侧五个停靠面板 | a61 深度，数字原样、测试钉死 |
| 原地（reveal） | 对话框、遮罩、页面、文件、后台任务、个人主页、设置页、首页、会话内容 | 只用透明度：进 base，出 base-out |
| 浮层（pop） | 输入框的权限 / 模型浮层、会话右键菜单、全局右键菜单、上下文面板、提示、toast | 只用透明度：从 .72（提示和 toast 从 0）进 fast，出 fast-out，`in` 曲线 |
| 折叠（fold） | 过程、日志、侧栏、搜索框、详情…… | 行高走布局：几行 base，一块 / 一个列表 flow，一轮结束 panel；收起时字先淡（fast），展开时空间先长、字晚一拍到 |
| 标记（mark） | 选中滑块、图标、珠子、状态点 | `glide` 或弹簧；滑块的时长随距离，flow 到 panel（`travelMs`） |

## 四、没动的（以及为什么）

- **a61 停靠动画**：`workspace-panels.css` 里 286/88/92、292/72/78 的数字和 `scale(.988/.99/.994)` 原样；布局 FLIP 的 390 现在写成 `DUR.panel`，曲线 `EASE.move`，数值不变。
- **发送动画**（`sendFlight*.ts`、`send-flight.css`、`loom-user-*` 关键帧）：物理，不是档位；它自己的曲线 `--loom-generation-pop` 是样式表里唯一允许声明的曲线。
- **图标手势的长度**：`--ic-t-run` 700 / `--ic-t-write` 640 / `--ic-t-spin` 900 是图标自己的；其余图标节奏（按下 90、回落 260、抬起 520、画线 390）现在就是这把尺子上的刻度（`--ic-t-*` 指向 `--loom-dur-*`），弹簧是同一条。
- **氛围循环和一次性的光**（宠物、侧栏标记、护航光点、扫光、涟漪）：周期不是档位，`test_motion_scale_contract.py` 里有一张按名字列出的小名单。
- **右侧工具栏**（`right-tool-dock.css`、`RightToolDock.tsx`，`e5c1574b`）：另一个会话在同一时间写的、自己的一套动效（弹簧弹出、错峰到场、滑块、等指针停下才出现的名字），连同它自己的定时器和浏览器测试。先不动它，等它定下来再放上这把尺子；`test_motion_scale_contract.py` 里按文件名列着，名单不会悄悄变长。任务进度面板（`task-progress-panel.css`）已经在面板语言上，只有两处 160 / 180ms 的颜色过渡和一个保留时长被收进尺子。
- **“减少动态”**：令牌在 `@media (prefers-reduced-motion)` 和 `[data-loom-reduced-motion]` 下折成 1ms（`motion-tokens.css`），所有按尺子写的东西自动不占时间；各文件里原有的 `animation: none` 规则留着（循环和图标还需要它们）。

## 五、顺手修的

- `.wv-hint-glow` 的动画一直没跑：它引用了从未定义的 `--wv-ease-inout`，整条 `animation` 声明在计算时失效。现在引用 `--loom-ease-inout`，等待提示旁的光条会呼吸（compositor 属性，一个 18×3px 的元素）。
- `useReducedMotion.ts` 已经有一个“现在是否减少动态”的函数，App、设置页、侧栏菜单、右键菜单各抄了一份；现在都用 `prefersReducedMotionNow()`。
- 六条无人引用的关键帧（`loom-account-backdrop-in`、`loom-account-dialog-in`、`model-panel-enter`、`model-panel-action-enter`、`orbit-rotate`、`spark-float`）删除。
- 输入框三个控件的标签在悬停 / 展开时会右移 .35px：字移动不到一个像素，只会让字边发虚，去掉（只变色）。设置导航行的标签文字上有一对 `translate3d(0,0,0)` ↔ `none` 的“过渡”，什么也没动，只是每次翻页多跑一条动画，去掉；只有图标留着那 1px 的轻推。
- `useMotionPresence` 的默认保留时长和 `presentationTiming.ts` 里几个“某某要多久”的常量（`TURN_FOLD_MS`、`RUN_STRIP_EXIT_MS`、`Crossfade` 的时长）由尺子派生。

## 六、加一个新的动画

1. 时长只写 `var(--loom-dur-…)`，曲线只写 `var(--loom-ease-…)` / `var(--loom-spring-…)`；脚本里用 `DUR` / `DUR_OUT` / `EASE` / `SPRING` / `RETAIN`。
2. 先问它属于哪种方言（上表）。带字的 → 透明度；要给它退出就用 `useMotionPresence(open, RETAIN.…)`，保留时长必须大于样式里的退出。
3. 折叠 = `display: grid; grid-template-rows: 0fr`，打开时 `1fr`，内层 `min-height: 0; overflow: clip`；时长 base（几行）或 flow（一块）。
4. 一次交互里的第二个东西只能是透明度。
5. 需要一个不在尺子上的数字：它多半是物理（发送、图标、氛围）；加进 `test_motion_scale_contract.py` 的名单时写明为什么。

## 七、验证

- `tests/test_motion_scale_contract.py`：尺子只写一次、脚本里的复本与它相等、保留时长由退出派生、“减少动态”折叠时钟、令牌第一个加载、样式表里**没有**自己写的时长或曲线（可疑项报出文件和行）、折叠不比悬停快、带字的入场关键帧不含位移 / 缩放 / 模糊、脚本里没有数字时长、判断“减少动态”的函数只有一个（旧的氛围代码列在一张只会变短的名单里）。
- 改动的旧契约测试（面板语言、面板布局、全局动效、设置导航、任务流、胶囊、上下文表、运行条）把钉死的数字换成令牌，意图没变。
- `scripts/tests/motion-language-browser.mjs`：真浏览器里驱动浮层、菜单、设置翻页、过程折叠、侧栏折叠、会话切换、个人主页、停靠面板，读回每个动画**实际生效**的时长和曲线，断言它们都在尺子上、带字的东西没有位移、一次交互里移动的元素不超过预算。
- 工具：`scripts/motion-lab/spec.mjs` 把同一个记录器做成命令（同一批交互，列出每个交互真正跑了什么）。
- 浏览器测试在深色、浅色和“减少动态”三种会话里各跑一遍交互，约 80 秒，连续三次全绿；它**没有**接进 CI（真浏览器、依赖时间，CI 一红就会拦住发布）。静态的尺子契约（`test_motion_scale_contract.py`）在 CI 的全量 pytest 里。
- 起始时就红的浏览器测试（这一轮前后输出完全一样，不是这一轮引入的）：disclosure-motion、component-surfaces、sidebar-navigation、weave-flow、earlier-process、workspace-visual、task-panel-layout、project-send。`panel-language-browser` 在起点那次是红的（等不到 `.thread-header`），改完是绿的，起点那次应当是偶发。`send-flight-browser` 有一次整轮里超时（423s），单独连跑三次都在 75–90s 内通过。

## 八、没做 / 可以继续

- 没在 Electron / 165Hz 上看（无头 Chrome 里量的）。
- 氛围循环（宠物、侧栏标记、环境光、护航光点）的周期各自为政，没有收进尺子。
- 少数旧的氛围代码（宠物、软指针、扫光）自己判断“减少动态”，测试里有名单。

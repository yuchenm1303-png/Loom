# 会话交接

可以直接对 Loom 说：“把当前工作交给一个新窗口继续，带上已完成事项、下一步和验证记录。”

模型使用 `handoff_thread` 创建普通会话，不是后台子代理。接收会话出现在会话列表中，继承工作目录、模型、推理设置、权限、工具选择和语言；交接内容包含任务、摘要、已完成事项、下一步及证据引用，不复制整个对话和未闭合的工具调用。

桌面默认打开独立窗口；还可以指定分屏、当前界面或后台。网页没有桌面开窗能力时使用分屏，手机使用当前界面。窗口加载失败不取消已经建立的会话，交接记录保留打开入口。内置浏览器由主窗口承载，其他窗口需要回主窗口打开浏览器面板；关闭主窗口后，剩余会话窗口接替主窗口，原浏览器标签不迁移。

原会话收到回执后结束当前回合。接收方等原回合和它的后台执行停妥后开始；原长目标暂停，项目停止调度并禁止自动开启下一阶段。原预算不会重置、复制或自动转移；新会话的长目标仍需已授权的预算。原项目可由用户明确恢复。

原会话和接收会话都显示交接回执，可查看来源、任务、进度和执行状态。新窗口启动不是工作完成的证明；“接续回合已结束”仅表示该回合结束。

重复工具调用复用同一接收会话。同一次失败重试使用接收会话原有的交接包，并以回合 ID 比较更新，避免双击或重复请求再执行一遍。创建中断后的预留记录也可恢复。接收方不会因交接包中提到“开新窗口”就继续制造窗口；再次交接需要新的用户回合。

普通会话可发起交接，项目内部代理和子代理继续向它们的拥有者汇报。交接摘要和历史证据作为上下文，不能提高权限，也不能替代对现有文件和运行结果的检查。

# 图标与图标动效重做（2026-10-10）

起因：用户让我“仔细设计美化 Loom 前端各种图标的交互动画，精致简约即可”，随后放开范围：“可以随意修改，包括图标本体和形状”。
这一轮先用真实渲染量化现状，再把图标换成带命名部件的一套，把所有图标动作收拢到一个样式表里。
范围是**图标的悬停 / 聚焦 / 按下 / 展开 / 完成 / 加载**；运行时任务流（`weave.css`）、思考动画、宠物、品牌标志不在这一轮动。

## 在旧版上测到的问题

数字来自在 150% 缩放（DPR 1.5）的真实渲染里逐个悬停每个图标控件，量每个图形部件的包围盒变化（`icon-audit.mjs` 的前身）。

1. **动作小到看不见。** 49 个控件里，除设置齿轮（2.9px）外几乎都在 0.3–0.9px 之间：侧栏文件夹 0.37、复制 0.32、归档 0.38、置顶 0.55、搜索 0.91；在 150% 缩放下不到一个设备像素，同时还挂着 `filter: drop-shadow` 过渡（既贵又让线条发虚）。
2. **一半的规则从来没生效过。**
   - `icon-motion.css` 有 2449 行，是 v2 / v3 / v4 三代叠出来的；约 1000 行针对的是早已不在 TSX 里的结构（`composer-attach-glyph`、`composer-access-*`、`header-agent-*`、`header-review-*`、`header-preview-*`）。
   - 选择器和 lucide 真实输出的类名不一致：lucide 输出 `lucide-trash2`、`lucide-file-code2`、`lucide-code-xml`、`lucide-earth`，样式里写的是 `.lucide-trash-2`、`.lucide-file-code-2`、`.lucide-code-2`。垃圾桶“盖子掀起”、文件“代码标记分开”实测为 0 位移。
3. **同一件事被各文件各写一遍，互相盖。**
   - 加载图标有 16 套完全相同的 `rotate(360deg)` 关键帧，时长 620 / 640 / 700 / 720 / 760 / 800 / 850 / 900 / 1000 / 1100ms 各写各的。
   - chevron 的转动在 12 个文件里各有一份，输入框的下拉箭头在 5 个文件里定义了 7 次，曲线和时长都不同。
   - 控件自己的悬停上浮 / 按下缩放（消息操作、输入框、头部、发送键）和图标动作叠在一起，是靠 `transform: none !important` 压住的。
4. **只有悬停。** 没有按下反馈，打开 / 展开状态和图标没有联动，键盘聚焦没有对应动作，减少动态要在十几个地方各写一份。

## 做了什么

### 一套图标（`src/components/icons/`）

- 与 lucide 同名、同 props（`size`、`strokeWidth`、`className`……），只改 import 路径；`LucideIcon` 类型也保留。
- **67 个图标按语义重绘**（24 格、圆头圆角、轮廓和 lucide 一致，所以和没重绘的图标并排不违和），区别是结构：会动的部分是单独的元素，带 `li` 和一个名字（`li-lid`、`li-arrow`、`li-tick`……）。样式写“盖子抬起”，而不是“第三个子元素”。其余 82 个仍是 lucide，保持静止——不是每个图标都有话要说。
- 新画 / 并入的：**新对话**（页面 + 笔，悬停时笔落到线上写出一行）、**模型**（三层面板）、**表情**、**活动脉冲**、**侧栏三角**。它们原来是散在组件里的手写 SVG。
- 每个图标带 `data-icon="名字"`，`icon-motion.css` 只认这个名字，不再依赖 lucide 的类名拼写。
- 任务流（`WeaveFlow.tsx`）和工具标识（`ToolIdentity.tsx`）仍用 lucide：它们的动效归 `weave.css` / `tool-identity.css`。

### 一个样式表（`icon-motion.css`，2449 → 约 380 行）

设计原则：**控件不动，图标回应一次；幅度约一个线宽（图标坐标 1–2 个单位）；很少的图标动，所以动的那几个看得见。**

机制是三个“旋钮”（CSS 变量），由交互宿主（按钮、链接、菜单项、标签……）发布，宿主里的图标读取：

| 旋钮 | 何时为 1 |
| --- | --- |
| `--ic-on` | 指针在宿主上，或键盘聚焦；只给“工具”（图标按钮、带文字的操作），整行列表项不发 |
| `--ic-lean` | 同上，但列表行（菜单项、选项、标签、导航、卡片、窗口标题栏按钮）也发——它们的图标保持静止，只有“这里通往别处”的箭头 / chevron 会倾斜 |
| `--ic-open` | 宿主 `aria-expanded="true"` 或 `aria-pressed="true"` |

一个部件的姿态是旋钮的函数，例如垃圾桶盖是 `translate(0, calc(var(--ic-on) * -1.4px)) rotate(calc(var(--ic-on) * -11deg))`。所以：

- 进和出是同一条规则，不需要成对的 `:hover` 列表；宿主只在“被触发”时才声明旋钮，静止时从 `:root` 继承 0，一页图标没有额外成本。
- 进场用一条快起长尾的弹簧（`linear()`，阻尼 .74，约 3% 过冲，0.52s），出场用平缓的 ease-out（260ms）；这对时长和曲线也是旋钮（`--ic-dur` / `--ic-curve`），宿主被触发时换成弹簧。
- 所有位移都在 SVG 内部、用图标自己的坐标单位，14px 和 20px 的图标比例一致。
- 减少动态在这一处：时长变量坍缩，`--ic-on` / `--ic-lean` 永不置位；`--ic-open` 仍置位，因为展开的 chevron 是状态，不是动作。

词汇表（每个图标挑其一，各自一两个部件）：

| 动作 | 图标 |
| --- | --- |
| 倾斜（朝它指的方向，箭头头部先走、杆跟着拉长） | chevron、箭头、发送、回复、播放、外链、登出、下载 / 上传、面板的箭头 / 分隔线 |
| 整转（转完形状不变，所以不会留下半像素偏移） | 加号、X（90°）、刷新（180°）、齿轮（60°，一齿） |
| 转一点 | 搜索、钥匙、扳手、回形针、铅笔、点赞 / 点踩、重做 / 撤销 |
| 开合 | 垃圾桶盖、归档盖、锁的钩、文件夹 |
| 分开 | 复制（两页错开）、模型 / 图层（上下两层分开）、diff 的 +/−、分叉、链接、最大化、省略号（三点依次抬起，页面上唯一的错峰） |
| 描绘 | 对勾（被选中时在按钮 / 菜单项里画出来）、盾牌的对勾（悬停时重画）、眼睛的斜杠、活动脉冲沿折线跑一次、新对话的笔迹 |
| 眨眼 | 机器人、表情、终端光标 |
| 替换 | 发送 → 停止：箭头向上离开、方块从中心长出（和整块输入框的交叉淡入同步结束） |
| 旋转 | 加载（一直转）；任何图标加 `spinning` 就转（刷新） |

按下：图标缩到 .88（控件本身不动），松开时用同一条弹簧回来。

### 收拢

- **加载**：16 套关键帧 → 1 套（`li-spin`，900ms，`rotate` 属性、跑在合成线程）。`Loader2 / LoaderCircle` 本身就转；刷新类图标传 `spinning`（原来的 `model-spin`、`spin`、`is-spinning` 等类名删掉了）。圆环形的非图标 spinner 也改用同一套和同一个节奏。
- **chevron**：12 个文件里的旋转和位移全部删掉，由 `--ic-open` / `--ic-lean` 驱动；侧栏菜单的两个子菜单项补了 `aria-expanded`（原来只有 `submenu-open` 类）。逐个确认了所有展开宿主都带正确的 `aria-expanded`：项目折叠、过程折叠、思考、检查器事件、子代理卡片、输入框三个下拉。
- **控件不再自己动**：消息操作、头部图标按钮、工作区入口、输入框工具栏、检查器关闭键、项目面板按钮、任务计划的关闭键，悬停上浮 / 按下缩放都去掉了（发送键原本就被 `!important` 压成静止，没有再动）。背景淡入、描边、聚焦环不变。
- **旧的重复规则**按“动效声明”逐条剪掉（`composer*.css` 四代、`header-*.css`、`sidebar.css`、`settings-*.css`、`model-*.css`、`turn-flow.css`、`inline-thinking.css`、`Inspector.css`、`sub-agent-workspace.css` ……共约 94 个文件的 3000 行删减、470 行新增），颜色、尺寸、布局一律没动。
- 头像悬停的光环和状态点放大从旧文件移到 `account-auth.css`（简化：光环淡入，不再旋转）。头部状态球的声呐动画没有保留：那个入口当前被 `workspace-surface-refinement.css` 隐藏（`display: none !important`）。上下文用量条悬停的光带在 `context-meter.css` 里有更新的一份，旧的重复那份随旧文件去掉了。

### 保持静止的地方

- 菜单项、选项、设置导航、标签、卡片、窗口标题栏按钮（用 `data-ic-row` 标记，或 `role=menuitem|option|tab`）：图标不动，箭头倾斜。一列十几个图标各演各的是噪声。
- 状态图标（信息、警告、云、文件类型……）和没有重绘的 82 个 lucide 图标。

## 验证

- **真实渲染逐帧**：`icon-film.mjs` 在 DPR 1.5、16px 下按 0–500ms 取帧（暂停动画再定位时间，不靠计时），逐个看了新对话、垃圾桶、齿轮、复制、chevron、箭头、钥匙、回形针等；`icon-film-live.mjs` 在真实应用里看了消息操作、头部、输入框工具栏、侧栏行操作。全部 67 个图标 × 静止 / 悬停 / 按下 / 展开 / 展开且悬停 的状态图在深色下逐个看过，浅色下抽查了 8 个（姿态与主题无关，颜色走 `currentColor`）。
- **悬停实测**（`icon-audit.mjs`）：49 个主界面控件，没有“控件自己上浮”、没有图标根节点的 transform / filter 残留；幅度从 0.3–0.9px 变为约 0.8–3.7px（含旋转的包围盒变化）。设置页、模型面板、权限面板、右键菜单、检查器、账号、项目面板逐个场景审过；找出的残留（`model-core-redesign.css` 的 chevron 位移、账号卡片箭头、检查器关闭键、项目面板按钮上浮）都已清。
- **静止外观 A/B**：24 个可见图标控件，与旧版逐像素比较，23 个完全一致；唯一不同的是头部活动图标，因为旧的不透明度规则随旧文件一起去掉了，已在 `Pulse` 里按旧值（.78）补回。
- **展开状态**（`state-check`）：项目折叠 90° ↔ 0°、过程折叠 0 ↔ 90°、两个输入框下拉 0 ↔ 180°，各转一次，没有“两处都转、抵消回 0”。
- **减少动态**：系统级和应用设置两种方式下，图标不取姿态、时长坍缩、展开的 chevron 仍然显示展开。
- **测试**：新增 `icon-motion.test.mjs`（7 条：样式引用的图标和部件都存在、图标里每个命名部件都有人动它、只有 `icon-motion.css` 能写部件名 / 旋钮 / 私有 spinner 关键帧、圆环 spinner 同一节奏、**样式里每个 `.lucide-*` 类都是 lucide 真的会输出的**、所有组件从图标模块 import）和 `icon-motion-browser.mjs`（真实悬停每个图标、键盘聚焦、展开的 chevron、减少动态、列表行 vs 工具、加载节奏、按下）。两组都做了突变检查（故意弄坏对应实现，测试变红）：7 + 6 个突变全部抓到。
- 已有测试：Python 的 UI 源码契约测试（约 20 个文件）和 renderer 的 `scripts/tests/*.test.mjs` 都没有新增失败；仍红的 4 条在改动前的 `HEAD` 上就红（输入框 `composer-glow` / 工作区几何相关的 3 条 Python 契约测试，和 `signed-out users cannot run or switch models` 1 条 node 测试）。`tsc --noEmit`、`vite build` 通过，构建后的 CSS 里 `linear()`、`calc()` 都原样保留。
- **性能**：仓库自带的 `long-session-bench.mjs following`，新旧三轮交错取中位数：样式重算 3.9s 对 5.1s、重算次数 +5%、布局 0.58s 对 0.67s（开发模式、噪声很大，只能说没有变差；删掉了约 2000 行图标样式，没有新增会随历史增长的选择器，也没有 `:has()`）。

## 没做 / 已知

- **没有在 Electron 真机和 165Hz 显示器上看**；无头 Chrome 的帧率不能当结论。幅度是在 150% 缩放的真实像素上定的，其它缩放比例（界面缩放 90–130%）按比例缩放，没逐一看。
- 头部的三个工作区入口（子代理 / 审查 / 产物）目前被样式隐藏，所以它们的图标动作（分叉、diff、面板）写好了但在主界面看不到；它们在检查器和其他位置的同款图标是看得到的。
- 82 个没有重绘的 lucide 图标保持静止。要给其中某一个加动作：在 `icons/glyphs.tsx` 里按 lucide 的轮廓拆出部件并命名，在 `icon-motion.css` 里写姿态，`icons/index.ts` 的导出名不变。
- 发送 → 停止的替换只在整块输入框交叉淡入的 280ms 内演出；复制 → 对勾只给新出现的对勾加了描绘，复制图标本身没有退场。

## 以后怎么加一个动作

1. 在 `icons/glyphs.tsx` 里把会动的部分拆成带 `li li-<名字>` 的元素（整个图标一起动用 `<g className="li li-all">`）。
2. 在 `icon-motion.css` 里写 `[data-icon="x"] .li-<名字> { transform-origin: …; transform: …calc(var(--ic-on) * 数值)… }`。方向类动作读 `--ic-lean`，转动 / 开合 / 分开读 `--ic-on`，展开状态读 `--ic-open`。
3. 用 `icon-film.mjs --icon x --size 16 --dsf 1.5 --zoom 3` 看真实像素下的帧；`icon-motion.test.mjs` 会在名字对不上、或者画了部件却没人动它时变红。
4. 不要在别处给图标写 `transform` / `filter` / `animation`：`icon-audit.mjs` 和 `icon-rules.mjs` 能找出还在叠加的旧规则。

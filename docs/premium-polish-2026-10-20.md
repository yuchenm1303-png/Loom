# 简约高级：字重是真的，装饰退场，面板说同一种语言（2026-10-20）

起因：用户说“请帮我仔细优化美化 loom 的整个前端包括动画吧，你拥有最高权限，你可以随意发挥，按你的思路设计和修改所有内容和布局，简约高级即可”。
前几轮（`docs/quiet-ui-2026-10-18.md`、`docs/motion-language-2026-10-18.md`、`docs/panel-language-2026-10-16.md`）已经收了字号、动画时间和面板外形；这一轮先把每个界面在两种主题、两种语言下都截了图（约 80 张），从看得见的问题开始。

## 一、最大的发现：界面要的字重，Windows 一直没给

设计里只有 400 / 500 / 600 / 650 四个字重，但画出来的不是这样（在仓库自带的 Electron，也就是 Chrome 136 里，用画布量墨量）：

| | 400 | 500 | 600 | 650 |
| --- | --- | --- | --- | --- |
| Segoe UI Variable Text（按字族名取） | 2091 | **2808**（= Semibold） | 2808 | **3666**（= Bold） |
| MiSans（这台机器只装了 `MiSans-Regular.otf`） | 2954 | 2954 | **4228**（假粗体） | 4228 |
| 改成 `local()` 可变字体之后：拉丁 | 2125 | 2482 | 2850 | 3261 |
| 改成 `local()` 可变字体之后：中文（Noto Sans SC） | 2817 | 3469 | 3887 | 4086 |

按字族名取系统字体时，浏览器只能拿到它的“命名实例”：Segoe UI Variable Text 只有 Regular / Semibold / Bold，所以所有 500 的按钮、标签、列表项其实都是半粗体；中文只有一个 Regular 文件，600 和 650 是把它描粗的假粗体（之前的笔记说 MiSans 每档都有，是错的）。
`styles.css` 现在用 `@font-face { src: local(...); font-weight: 100 900 }` 把同一个已安装文件当可变字体用：每个字重都是真的，光学尺寸也跟着字号走（28px 的标题自动用 Display 的字形），新字重实例的成本从 16–20ms 降到 2–3ms（`font-warmup-browser.mjs` 的门槛随之改为 1ms）。没有这些字体的机器会跳过这些 face，退回原来的栈，什么都不下载。
代码字体从 Consolas 换成 Cascadia Mono，并用两段 face 把 400/500 画在 350（它的 Regular 每像素比 Consolas 深五分之一，也比正文深）。

## 二、退场的装饰

- 首页隐藏但仍挂载的“轨道标志”（12 层动画）、侧栏里没人渲染的品牌轨道、会话背后漂移的两团模糊光斑和网格（一个 blur 滤镜、两条循环、8 位色带出现的一圈圈色阶）、标题栏在不透明底色上的 backdrop 模糊、首页卡片跟随指针的光（一个全局 pointermove 监听）。
- “环境光”设置现在只在首页问候语后面放一束静止的光；会话本身是干净的底色。

## 三、外观（第一批，7d82041b）

- 侧栏：“新对话”是一行而不是一块着色的板（羽毛笔保留紫色）；选中的会话是中性的凸起底，没有紫色竖条和渐变；选中和未读的标题用 500。
- 标题栏：侧栏开关是一个小小的灰色三角（之前它“按下”的状态是紫色），标题 600；浅色主题下标题不再被画成次要灰。
- 首页：四张起步卡片同一种颜色、图标没有彩色底块、卡片是发丝线而不是浮起的阴影，箭头只在指针在时出现；活跃卡片里的“连续 3 天”是一个词，不是药丸。
- 消息：Markdown 两种主题用同一组令牌；表格是表头线下的几行字（没有外框和竖线，左边和段落对齐）；引用是一根中性的竖线；代码块是一个整体，语言和复制按钮在里面；列表符号用次要灰；用户气泡圆角 14px；工作区发丝线 .09。
- 状态色更沉稳（OKLCH：成功 .78 / .135，失败 .72 / .155），去掉了发光；审查里的增删行只是一层淡淡的底色，代码保持正文颜色。
- 输入框：工具栏里没有竖分隔线，图标 16px，悬停是中性底色；上方的项目行按界面语言写“本机 / 文件 / 仓库 · PR”。
- 弹层和设置：权限标签是词不是药丸；设置导航的分组用句子大小写，选中页是中性的凸起底，分段控件的滑块是中性的，状态是带点的彩色词，值是普通文字而不是代码框，图标底块是单色，开关旁边不再重复写“开启”。

## 四、第二批

- **一种语言**：项目面板（连同仓库、记忆、说明文件三张卡）、子代理、产物、文件这几处原来只写了中文，英文界面里也是中文；检查器和推理控件只写了英文，中文界面里出现 “Execution stream”“Reasoning”。现在都有两种语言。设置的词典补上漏掉的几句（浏览器桥接离线、OAuth 备用方式、“Fixed”），技能页两处中文字面量改成英文源文，让词典能翻回中文。
- **标签是词，不是字母间距拉开的大写**：28 条规则去掉 `text-transform: uppercase` 和字距，字重 500（中文没有大写，英文小标题叠在中文标题上面只是装饰）。
- **项目面板**是一列用发丝线分开的段落：原来每一块外面一个卡片、卡片里有小卡片、小卡片里还有凹槽，三层框。每段一个标题（英文小标题去掉），段落里的操作是安静的文字按钮，“暂无内容”是一行字，“下一步能力”这张列出还不存在功能的卡片删掉了。
- **子代理**的状态只说一次：彩色的词加图标，没有药丸，也没有卡片左边的彩色竖条；头像和筛选计数是中性的。
- **个人主页**：卡片是平的（发丝线，没有阴影和内高光），顶部一束静止的光代替两团彩色光，分区图标中性，头像是纯色，账号类型是一个词；年度热力图画出范围内的每一天、每个月都有标签（以前没有记录的日子不画，看起来像图表坏了）。
- 决定卡片里“建议”的选项、浅色主题的差异行，也按同样的规则：强调色的一个词；一层淡淡的含义色，代码用正文颜色。
- 输入框变窄时（旁边开着审查或面板）控件保持一行：自身宽度小于 600px 时，附件按钮只留图标。

## 五、顺手修的

- `panel-switching.css` 用 `html[data-loom-panel-handoff]:has(.loom-tool-button[aria-pressed="true"])` 问“有没有工具被按下”，这是挂在根上的 `:has()`，运行时每次 DOM 变化都要重算（`css-has-invalidation.test.mjs` 因此是红的，CI 的脚本步骤也红）。交接本身已经带着意图（right-open / right-swap / right-close），改用它。
- 另一个会话的 `1ea15edb` 有意去掉了切换会话时的整面淡入、并让“出生动画”认得历史记录，但两条 Python 合约测试还在断言旧行为，CI 的 pytest 因此连续两次失败、安装包没有发布。测试改成断言新行为。
- 第二批推送之后 CI 又红了，和界面无关：GitHub 把 `ubuntu-latest` 换成了 26.04，这个镜像自带 `bwrap`。`SandboxManager` 没拿到可执行文件时会去 PATH 里找，于是两条描述“没有沙箱后端”的测试找到了一个真的后端（`test_bootstrap` 等不到审批，`REQUIRED` 变成允许）。两条测试现在把启动器从查找里藏起来，在任何机器上意思都一样（`a3d2f010`）；产品行为没变：沙箱可用时命令在沙箱里直接运行。

## 六、动画

这一轮没有改动画的“尺子”：`spec.mjs` 跑同一批交互，仍是 22 种“时长 + 曲线”组合，和动画语言那一轮结束时一样。改的是：去掉了上面那些常驻循环（空闲时页面上没有在跑的动画，运行时只有侧栏那个运行中的小点在呼吸）；首页卡片的箭头在悬停时淡入并轻推 1px；输入框控件的悬停只变色。

### 检查器的退场（第三批）

- `933842fe` 为了不让截图阻塞输入，让所有右侧变化都不走 View Transition。审查、子代理、产物、项目这几块面板有自己的动画（`.pl-dock`：淡入、漂移几像素，panel 时长，进 out 出 in），检查器原来靠 a61 快照，于是只剩下兜底：打开时从全透明淡入，关闭时第一帧就被 `visibility` 藏起来，淡出和位移在看不见的地方跑完 390ms。
- 现在检查器和其它面板一样离开：panel 时长、in 曲线、淡出并向右漂移 16px，退场结束才隐藏。它的网格轨道在关闭时立即收起，所以退场期间它被钉在原来的位置（在自己的网格区域末端绝对定位，`grid-column: 3 / 4`：绝对定位的网格子元素，`auto` 的结束线是容器边缘，不写会越过工具栏 66px），会话在它下面滑进来。被另一个面板替换（right-swap）时仍然立即消失，不和新面板叠在一起。
- `motion-language-browser.mjs` 还在等右侧已经不用的 a61 快照动画、以及 `1ea15edb` 去掉的切换淡入，所以一直是红的。现在它读的是现在的规则：面板只漂移几像素（不超过 24px），进 panel/out、出 panel/in，退场结束才隐藏；切换会话时会话以完整不透明度出现。三个变异（第一帧就隐藏、长距离滑动、退场用 out 曲线）各自让它以对应的消息失败。

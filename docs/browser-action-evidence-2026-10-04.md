# 浏览器执行证据补齐

实际长任务中，模型反复拿页面里的旧 event #13 解释后续点击，并把未执行动作、页面变化和功能通过混为一谈。本轮只修可验证的信息链路缺陷，不再凭此宣称解决全部表达与效率问题。

## 修改

- 浏览器结果保存来源 call ID、请求 revision、此前观察 revision、返回 revision、执行状态与可观察效果。功能结论明确标记为 `not_assessed`，不由 Host 从 DOM 变化自动推导。
- 原来被丢弃的视口宽高进入精简结果及瞬时观察。只保留有限的数值几何字段，不把任意 `page_info` 注入历史。
- 当前页快照明确标注来源，并说明它包含全页历史内容，不等于本次动作新增的事件日志。
- 收尾评估直接接收结构化动作证据，即使结果正文被截短，仍能区分未执行与功能失败。非浏览器结果不添加空字段。

## 验证与限制

回归覆盖真实模型请求构建和收尾评估的数据传递、过期动作不执行、动作前后 revision、视口信息及无关元数据隔离，同时复查长证据评估、继续执行及上下文整理路径。

这些字段提供可追踪的事实，不保证模型一定正确推理；全页里的事件 ID 仍由页面定义，Host 不解析任意网页日志，也不会把它们自动认作测试证据。表达质量、计划使用、压力测试覆盖和真实模型耗时仍需固定任务复验。本轮没有改变用户的模型或思考配置，没有加入关键词收尾判断或调用次数上限。
